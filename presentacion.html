01 · Introducción

¿De qué trata Urban Roots?

  • Una revista digital sobre los orígenes de la música urbana uruguaya
  • Cuatro géneros explorados: Carnaval, Rock, Rap y Plena
  • Cada artículo conecta historia, cultura y música desde una perspectiva diferente
  • Hilo conductor: ¿qué pasa cuando algo de afuera llega a Uruguay y se vuelve nuestro?
02 · Desarrollo

Tecnologías utilizadas

  • Frontend: HTML, CSS y JavaScript puro con Bootstrap 5 Estructura semántica, diseño responsive desde celular y tablet
  • Backend: Node.js con Express, una API REST que sirve los artículos Endpoint GET /articulos/:id, los datos se inyectan dinámicamente en la página
02 · Desarrollo

Desafíos y lo que más nos orgullece

  • Desafío 1: Implementar un sistema de temas Solución: usar variables de CSS y las configuramos con JavaScript basado en la elección del usuario
  • Desafío 2: Implementar contenido de los artículos de forma dinámica Solución: creamos un backend que permite cargar datos desde fuera y lo agregamos a la página
  • Lo que más nos orgullece: hacer un sistema de temas con dos familias de paletas de colores distintas, totalmente funcional en toda la revista.
03 · Diseño

Decisiones de diseño

  • Paleta de colores: 2 familias en versión oscura y clara: Mural Urbano y Crepúsculo Rioplatense El usuario elige su tema desde el footer y la elección persiste entre visitas
  • Tipografía: Inter para cuerpo, Syne para Mural Urbano, Playfair Display para Crepúsculo Rioplatense La fuente cambia con el skin: la personalidad visual se transforma junto al color
  • Layout: Header sticky (permanece en el tope de la pantalla siempre), cuerpo de artículo centrado al 65% del ancho de pantalla, artículos listados en una grilla dinámica y pié de página con formulario de suscripción
  • Elementos visuales: Rotación de imágenes con una superposición de graffiti, botones con estilos variados, tarjetas de artículos, banner de artículo con imagen de fondo y overlay semitransparente en los artículos
  • Accesibilidad: Atributos "alt" en todas las imágenes, para lectores de pantalla y dispositivos que no admiten la carga de imágenes, navegación utilizando el teclado y contraste revisado en las 4 paletas de colores
04 · Demo

Recorrido por la revista

  • Inicio: hero section con carrusel, sección "Sobre nosotros", grilla de artículos en español e inglés
  • Artículos: banner con imagen de fondo, cuerpo con texto, títulos e imágenes con pie de foto, sección "Sobre el autor"
  • General: header sticky con barra de navegación, footer con formulario para newsletter y selector de tema

06 · Reflexión

Lo que aprendimos

  • Mayor desafío: coordinar contenido, diseño y código en paralelo entre cuatro personas
  • Mayor aprendizaje técnico: hacer una integración real de frontend con backend via API REST
  • Mayor aprendizaje de diseño: las variables CSS permiten sistemas de temas complejos con poco código
  • Lo más satisfactorio: ver los artículos reales funcionando con datos del backend
  • Los que nos gustaría mejorar: formulario de newsletter funcional, más artículos, buscador por género
